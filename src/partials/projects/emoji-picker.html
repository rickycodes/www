Emoji Picker

A vanilla JavaScript emoji picker that replaces a Basecamp emoji string, e.g. :dog:, in a text input with the equivalent Unicode character, e.g. 🐶. This uses native, browser-supported ES6 modules (no bundling!), so you may need to enable them for it to work. A similar feature exists in the popular cloud-based team collaboration tool Slack.
