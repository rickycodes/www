Colophon

A small note about the machinery behind this website. It is hand-written, statically assembled, and served as a collection of files.

Front end
Semantic HTML, CSS, vanilla JavaScript, and a small Rust/WebAssembly layer for interaction.
Build
Rust, stdweb, and cargo-web target wasm32-unknown-unknown. Bash scripts assemble the HTML, minify assets, and add the build revision.
Tooling
Terser minifies the deploy JavaScript; html-minifier-next keeps the generated document compact.
Infra
Built and deployed with GitHub Actions to GitHub Pages, with ricky.codes as the custom domain.
Source
The whole thing is open source on GitHub.

Fonts are IBM Plex Sans and IBM Plex Mono. Icons and cursors were made with Dotgrid.
